# 批零联动定价台（油品价格维护）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在油品挂牌价维护基础上扩展的批零联动定价闭环，数据保存在浏览器 localStorage，刷新后记录、版本与阻断原因保持一致。

## 业务规则

- 调价单字段：站点、油品、零售升价（元/升）、批发吨价（元/吨）、密度（kg/L）、生效日、操作员、复核人。
- 换算：每升批发价 = 批发吨价 × 密度 ÷ 1000；批零差 = 零售升价 − 每升批发价。
- 批零差低于 0.5 元时必须填写复核人，且复核人不得与操作员相同（操作员不得自审）。
- 同站点 + 同油品 + 同生效日不可重复发布。
- 任一字段无效时整批拒绝，不写入任何数据，并保留表单全部输入与阻断原因。
- 发布后价格与密度冻结；更正必须填写原因，在原记录上追加新版本，旧值完整保留。

## 分层结构

- `src/domain/pricing.ts`：数据模型与纯函数（吨升换算、批零差、调价单/更正单校验）。
- `src/storage/priceStorage.ts`：localStorage 读写与种子数据。
- `src/stores/pricingStore.ts`：Pinia 数据层，编排发布、版本化更正与持久化。
- `src/App.vue`、`src/components/PriceRecordCard.vue`：界面层，录入、实时换算预览、阻断提示、版本历史与更正。
