# 油品批零联动定价台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

- 调价单整批录入：站点、油品、零售升价（元/升）、批发吨价（元/吨）、密度（kg/L）、生效日。
- 换算：每升批发价 = 批发吨价 × 密度 ÷ 1000；批零差 = 零售升价 − 每升批发价（界面实时联动显示）。
- 复核：批零差低于 0.50 元/升时必须填写复核人，且复核人不得与操作员相同（操作员不得自审）。
- 唯一约束：同站、同油品、同生效日不能重复发布（批次内重复同样阻断）。
- 整批事务：任一行数据无效（含越界密度、非法日期、重复发布、复核缺失等）→ 整批拒绝，不写入任何记录；用户输入与逐行阻断原因原样保留并持久化。
- 冻结与版本：发布成功后价格与密度冻结；更正必须填写原因，生成新版本，旧版本只读保留，版本链可展开查看。
- 阻断留痕：每次整批拒绝写入阻断事件（含逐行原因），刷新页面后记录、版本与阻断原因保持一致（localStorage）。

## 分层结构

- `src/pricing/types.ts`：数据模型（草稿、已发布记录、版本、阻断事件）。
- `src/pricing/constants.ts`：站点/油品、价格与密度区间、批零差阈值。
- `src/pricing/conversion.ts`：纯函数的换算与校验（无存储、无 DOM 依赖，可直接单测）。
- `src/pricing/storage.ts`：localStorage 序列化读写，后续替换为后端接口只需改这一层。
- `src/pricing/store.ts`：Pinia 编排层（整批发布事务、唯一约束、复核、更正版本）。
- `src/components/*` + `src/App.vue`：界面层，只做展示与交互。
